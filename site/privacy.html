PRIVACY POLICY

SpeedySlate Browser Extension Privacy Policy

Last updated: November 24, 2026

1. Zero Developer Data Collection

SpeedySlate operates entirely client-side inside your web browser. The developer does not operate any analytics, telemetry, tracking pixels, user accounts, or proxy servers. Your browsing history, enabled website list, and API keys never leave your device except to communicate directly with the translation API provider you explicitly configure.

2. Local Optical Character Recognition (OCR)

In Hybrid OCR mode, comic and webtoon images on websites you explicitly enable are processed locally on your device using WebGPU or WebAssembly ONNX Runtime models cached in your browser's IndexedDB. Raw images are not uploaded to any developer server.

3. Third-Party Translation API Requests

Extracted dialogue text (or compressed panel slices when Multimodal Vision mode is selected by the user) is sent directly from your browser to the translation endpoint you choose—such as Google Gemini, Groq, DeepSeek, OpenRouter, OpenAI, Google Translate, or your own local Ollama instance—governed by that provider's respective privacy terms.

4. Local Browser Storage & Permissions

SpeedySlate uses local browser storage solely to save your extension settings, user-added domain list, custom glossary, cached translations, and downloaded ONNX OCR weights. You can clear all cached data at any time with a single click inside the extension's System tab or by uninstalling the extension.

5. Chrome Web Store Limited Use Disclosure

The use of information received from Google APIs and website content permissions adheres strictly to the Chrome Web Store User Data Policy, including the Limited Use requirements.
